Fluxos

Como funciona

→
Atendimento pelo chat do site
1
Visitante clica no botão de chat que aparece no site do cliente
2
O chat se conecta ao servidor em tempo real e abre uma conversa automaticamente
3
A mensagem chega ao servidor, é salva e aparece instantaneamente no painel dos operadores
4
O operador responsável pelo canal vê a mensagem em tempo real e responde pelo painel
5
Quando a conversa é encerrada, a IA gera um resumo automático e salva para consulta futura
→
Recebimento de E-mail
1
Um e-mail chega no endereço configurado para o canal (via Cloudflare ou Mailgun)
2
O servidor recebe o aviso automático, lê o remetente, o assunto e o conteúdo do e-mail
3
O sistema identifica a qual canal aquele endereço pertence e cria ou atualiza a conversa correspondente
4
O painel dos operadores é atualizado na hora — o operador daquele canal recebe uma notificação
5
O operador responde pelo painel e o sistema envia o e-mail de volta ao visitante via Brevo
→
Atendimento via Telegram
1
O administrador conecta uma conta do Telegram pelo painel, informando número e credenciais
2
O servidor fica escutando as mensagens recebidas nessa conta e as vincula ao canal correto
3
A conversa aparece na fila do operador responsável por aquele canal do Telegram
4
O operador responde pelo painel e o servidor encaminha a mensagem de volta pelo Telegram
5
Arquivos de áudio, imagens e vídeos são salvos no servidor e exibidos normalmente na conversa
Módulos

Componentes principais

Widget Embed
Um arquivo pequenininho que você cola em qualquer site com uma única linha de código. Quando o visitante abre a página, o chat aparece, se conecta ao servidor em tempo real e já cria uma conversa automaticamente.
Instalação com uma linha de código no site
Também pode ser ativado via comando direto no site para quem prefere controle total
Cor do chat ajustável para cada empresa
Se a internet cair, o chat reconecta sozinho quando voltar
window.ChatFlow.mount({ serverUrl: 'https://api.exemplo.com', organizationId: 'uuid', primaryColor: '#4f46e5' })
✓ chat ativado no site — conexão em tempo real estabelecida — conversa criada
Motor de E-mail
Recebe e-mails que chegam via Cloudflare ou Mailgun, cria ou atualiza a conversa correspondente e envia respostas pelo Brevo. O operador não precisa abrir nenhum cliente de e-mail — tudo aparece no painel.
Funciona com Cloudflare Email Routing e Mailgun
Lê e organiza remetente, assunto e conteúdo do e-mail automaticamente
Mantém o histórico do mesmo assunto agrupado numa conversa só
Salva arquivos anexados no servidor
aviso automático de e-mail recebido: { remetente, destinatário, assunto, corpo }
✓ conversa de e-mail criada — operador notificado em tempo real
Integração Telegram
Conecta contas do Telegram ao sistema. Cada conta tem suas próprias credenciais. Mensagens de texto, áudios e imagens que chegam pelo Telegram aparecem na mesma fila do painel, junto com as outras conversas.
Várias contas do Telegram conectadas ao mesmo tempo
Envio e recebimento de mensagens de voz
Se a conexão cair, o sistema reconecta automaticamente
Mostra o estado da conexão: desconectado, conectando, conectado ou aguardando verificação em dois passos
preparar banco de dados para Telegram e vincular operadores
✓ tabela de canais Telegram criada — operadores vinculados ao canal
Resumos IA (Claude)
Quando uma conversa é encerrada, o servidor pede à IA da Anthropic (Claude) que leia o histórico e escreva um resumo do atendimento. Esse resumo fica salvo e aparece no painel para consulta futura.
Resumo gerado automaticamente ao encerrar qualquer conversa
Histórico de resumos acessível por conversa
Disponível para leitura direto pelo painel
Sem configuração extra — só precisa da chave de acesso à IA no arquivo de configuração
pedido pro servidor: encerrar conversa 'conv-uuid'
✓ Claude gerou resumo — salvo no banco de dados — conversa arquivada
Respostas Rápidas com Salvamento Automático
Os operadores podem salvar mensagens que usam com frequência para enviar com um clique. E tem um recurso inteligente: se o operador digitar a mesma mensagem 3 vezes ou mais, o sistema salva ela automaticamente como resposta rápida — sem precisar fazer nada.
Respostas pessoais de cada operador e respostas globais criadas pelo admin
As mais usadas aparecem primeiro na lista
Salvamento silencioso após a terceira vez que a mesma mensagem é enviada
Não duplica — se a mensagem já estiver salva, o sistema identifica e ignora
registrar envio da mensagem: 'Olá! Como posso ajudar?'
✓ contador chegou em 3 — mensagem salva automaticamente nas respostas rápidas
Gestão de Operadores e Canais
Tela para criar, editar e ativar ou desativar operadores, definir quem é administrador ou atendente comum, e escolher quais canais cada operador monitora. Assim cada um só vê o que é relevante para ele — sem poluição visual.
Criar, editar e ativar ou desativar operadores
Definir o operador principal de cada canal
Cada operador vê só as conversas dos canais que são dele
Modo de emergência: operador consegue ver todas as conversas, de todos os canais, quando necessário
pedido pro servidor: vincular operador ao canal Telegram como responsável principal
✓ vínculo criado — operador agora vê as conversas do canal Telegram

Próximos Passos

Priorizado por urgência

Alta Prioridade
IA respondendo na fila antes do operador
Antes de acionar um atendente humano, o Claude tenta responder sozinho usando o contexto da conversa — alivia bastante o volume em perguntas simples e repetitivas.
Subir tudo com um comando só
Um arquivo de configuração único que levanta o servidor, o painel, o chat do site e o banco de dados de uma vez, sem precisar configurar nada manualmente.
Avisos para operadores fora do painel
Quando chegar uma conversa nova, o operador recebe um aviso no navegador ou por e-mail — mesmo que o painel esteja fechado. Evita conversas paradas na fila sem ninguém ver.
Próximas Entregas
Passar conversa para outro operador
O atendente pode transferir uma conversa em andamento para um colega sem perder nada do histórico — essencial quando cada operador tem uma especialidade diferente.
Entrar com conta Google
Login dos operadores usando a conta Google, sem precisar criar ou lembrar de mais uma senha — facilita muito na hora de trazer novos atendentes.
Relatórios com filtro de datas
A base para os relatórios já está pronta no servidor; falta finalizar o cálculo por período personalizado e exibir os números na tela do administrador.
Fundação Técnica
Testes automáticos
O projeto ainda não tem verificações automáticas. Criar testes que rodam sozinhos garante que novas funcionalidades não quebrem o que já funciona.
Separação real de dados por empresa
Hoje o sistema ainda não isola completamente os dados de cada empresa contratante. Fazer essa separação no banco de dados é o pré-requisito para oferecer o produto como serviço a múltiplas empresas.
Publicação automática a cada atualização
Configurar um processo que, a cada mudança no código, verifica se tudo está certo e publica a nova versão automaticamente — sem intervenção manual e com muito mais segurança.
Filosofia

O que guia cada decisão

⭐
"O cliente fala pelo canal que já usa — o operador atende por um painel só"
PRINCÍPIO 01
Zero burocracia para quem quer ser atendido: abrir o chat ou mandar um e-mail já é suficiente para iniciar o contato
PRINCÍPIO 02
Operadores veem só o que é relevante para eles — cada um cuida do seu canal, sem perder emergências de vista
PRINCÍPIO 03
IA como assistente, nunca como obstáculo — ela ajuda com resumos e automação, mas não toma decisões no lugar do atendente
Filtro de feature
Uma funcionalidade nova entra no projeto se reduz o tempo de resposta ao visitante OU reduz o esforço mental do operador — o que for só burocracia administrativa fica para depois
