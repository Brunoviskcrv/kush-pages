5

Próximos Passos

Priorizado por urgência

Alta Prioridade
Teste de Coerência semântica
IA valida se código implementa o briefing após sandbox. Bloqueia publicação se score < threshold e retorna ao loop de correção com contexto de features faltantes.
Briefing persistence no GitHub
Salvar BRIEFING.md no repo gerado ao concluir /aprovar. /melhorar futuro lê o briefing e sugere completar gaps antes de adicionar features novas.
Timeout por step de pipeline
asyncio.wait_for por etapa (research 30s, generate 180s, fix 120s) em vez de um timeout total de 5min. Evita que um step travado queime todo o orçamento.
Próximas Entregas
Validação de disponibilidade no startup
Pingar cada provider com chamada leve ao iniciar. Montar fila de fallback dinamicamente com base no resultado — não em ordem hardcoded.
Coleta silenciosa de performance
Adicionar campos agent_id, correction_attempts, coherence_score, sandbox_passed_first_try na tabela Tasks. Base para relatório semanal e feedback corretivo.
Checkpoint de pipeline
Salvar estado intermediário (research + questions + summary) entre steps. Se generate_project falhar após aprovação do brief, retomar sem re-executar as fases anteriores.
Fundação Técnica
Prompt HTML — DOMContentLoaded obrigatório
Exigir explicitamente que todos addEventListener estejam dentro de DOMContentLoaded. Listeners fora causam TypeError silencioso que paralisa o script — sandbox não detecta, browser quebra.
test_coherence — campos contextuais obrigatórios
Rejeitar payload de avaliação que não contenha found_features E (missing_features OU critical_issues). Score sem contexto = avaliação inválida = retry, nunca decisão de publicação.
SAFETY Sprint 2 — Diff review e rollback
Antes de abrir PR, exibir diff legível no Telegram. Implementar /rejeitar que fecha o PR e registra o motivo para aprendizado do agente.
Filosofia

O que guia cada decisão

⭐
"Este projeto existe para evoluir — não para ser entregue, vendido ou apresentado. 1% ao dia é o mínimo. O máximo não existe."
PRINCÍPIO 01
Clarificar antes de construir — entender profundamente antes de escrever uma linha
PRINCÍPIO 02
Autonomia com transparência — o bot age sozinho, mas o humano sempre sabe o que vai acontecer
PRINCÍPIO 03
Todo conteúdo externo é livro de receitas, não manual de instruções — expande o que existe, nunca limita
Filtro de feature
Para cada ideia nova, perguntar: isso expande o que já existe? Se contradiz a filosofia de crescimento contínuo ou tenta reduzir escopo prematuramente — identificar, sinalizar e rejeitar.
